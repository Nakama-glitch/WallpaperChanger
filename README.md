# 桌面壁纸微调切换器 (WallpaperChanger)

**作者署名**：成遇知 | YouTube：[www.youtube.com/@cyzhi](https://www.youtube.com/@cyzhi)  
**开源协议**：完全开源免费（Open Source & Free），欢迎自由使用、修改与分享。

---

## 一、 工具概述

**桌面壁纸微调切换器**是一款专为 Windows 10 / Windows 11 设计的极简、轻量化桌面壁纸管理与自由排版工具。

针对日常切换壁纸繁琐、不同比例/分辨率的图片在桌面上容易被强行拉伸或裁切等痛点，本工具直接调用 Windows 系统底层原生图形引擎（GDI+）与系统 API，在完全不依赖任何第三方图像处理插件的前提下，实现了**实时预览、自由缩放、上下左右位置微调、背景色智能提取填充、单图独立布局记忆**以及**原壁纸无损备份与一键还原**等核心功能。

---

## 二、 核心功能亮点

1. **零第三方依赖，极速启动**
   * 纯 Python 标准库 + Windows 原生 GDI+ (`gdiplus.dll`) 编写，无需安装 Pillow、OpenCV 等任何外部扩展库，体积小巧，既可直接运行脚本，也可打包为单文件绿色 `.exe` 程序。
2. **专属目录结构，清爽不凌乱**
   * 自动在程序同级目录下识别或创建 `壁纸` 专属文件夹（存放所有待切换图片）与 `data` 数据目录（静默存放配置文件与壁纸备份），保持根目录整洁。
3. **自由 DIY 排版与单图独立记忆**
   * **实时 16:9 等比例预览**：支持缩放（`+` / `-`）、上下左右方向微调（`^` `v` `<` `>`）及一键居中复位（`•`）。
   * **三种背景填充模式**：支持纯黑背景、**自动提取图片主色调**沉浸填充，以及自定义取色器。
   * **单图参数锁定**：点击**“应用当前布局 (锁定记忆)”**后，该图片的缩放比例、偏移坐标与背景色会自动写入配置，下次切换回该图片时自动按专属布局显示。
4. **预览与切换分离，所见即所得**
   * 提供 **`← 上一张预览`** / **`下一张预览 →`** 按钮（同时支持键盘左右方向键），可在不改动当前桌面的情况下提前浏览并微调壁纸；确认满意后再一键应用，也可直接点击**“切换壁纸”**按文件名顺序快速轮播。
5. **物理级原壁纸备份与安全退出提醒**
   * 初次使用或检测到外部壁纸时，自动无损备份当前系统壁纸作为“唯一恢复源”。随时点击**“恢复原壁纸”**即可还原；若更换壁纸后未恢复直接关闭软件，会贴心弹窗询问**“是否恢复原桌面壁纸？”**。

## 三、 运行环境与打包说明

### 1. 运行环境要求
* **操作系统**：Windows 10 / Windows 11（64位）
* **Python 版本**：**Python 3.8 及以上版本**（已在 Python 3.11 / 3.13 环境下测试通过）
* **所需插件/依赖**：**无（0 第三方依赖）**。仅使用 Python 内置标准库（`tkinter`、`ctypes`、`winreg`、`json`、`os`、`shutil`、`webbrowser`），安装好官方 Python 即可直接双击运行。

### 2. 打包为独立 `.exe`（可选）
如需在未安装 Python 的电脑上运行，可使用 `PyInstaller` 打包为单个可执行文件：
1. 在程序根目录打开终端（CMD），安装打包工具：
   ```bash
   pip install pyinstaller
   ```
2. 执行打包命令（生成无黑框单文件程序）：
   ```bash
   pyinstaller -F -w -n WallpaperChanger wallpaper_changer.py
   ```
3. 将 `dist` 文件夹内生成的 `WallpaperChanger.exe` 剪切至 `WallpaperChanger` 根目录即可直接使用。

## 四、 使用说明与注意事项

### 目录结构规范
请确保文件夹结构如下所示（首次运行程序会自动生成缺失的文件夹）：
```text
WallpaperChanger/
├── WallpaperChanger.exe   (或 wallpaper_changer.py 运行程序)
├── 壁纸/                   <-- 请将您的所有壁纸图片放入此文件夹内
└── data/                  <-- 程序自动生成，用于存放配置记忆与原壁纸备份（请勿手动删除）
```

### 日常使用步骤
1. **放入壁纸**：将 `.jpg`、`.jpeg`、`.png`、`.bmp`、`.webp` 等格式的图片放入 `壁纸` 文件夹中。
2. **浏览与微调**：双击运行程序，使用 `←` / `→` 按钮（或键盘左右键）预览图片；利用右侧十字方向键和 `+` / `-` 调整画面位置与大小，选择喜欢的背景填充色。
3. **应用与锁定**：点击蓝色的**“应用当前布局 (锁定记忆)”**，壁纸会立即生效并永久记住该图片的排版参数。
4. **一键恢复**：若需还原回使用本软件前的系统默认壁纸，点击**“恢复原壁纸”**，或在关闭窗口时选择**“是”**即可。

### 注意事项
* **关于 `data` 文件夹**：`data\original_backup.png` 保存着您最初的系统原始壁纸，`data\config.json` 保存着每张图片的排版记忆，请勿随意删除或移动该目录。
* **系统壁纸显示模式**：为保证自定义缩放和偏移的精确度，程序在应用壁纸时会自动将 Windows 桌面契合度调整为**“居中”**模式并按屏幕物理分辨率精确渲染输出，属于正常底层机制。
* **热更新图片**：在程序运行期间，如果往 `壁纸` 文件夹中新增或删减了图片，无需重启软件，直接点击预览切换或**“切换壁纸”**即可自动识别最新列表。
